# 📝 To-Do List Application (Console-Based)

A simple and beginner-friendly To-Do List application built with Python. This console-based program allows users to manage their daily tasks efficiently by adding, viewing, and removing tasks. Tasks are stored in a text file, ensuring data persistence even after the program is closed.

## 🚀 Features

- Add new tasks
- View all existing tasks
- Remove completed tasks
- Store tasks in a text file (`tasks.txt`)
- Automatically load saved tasks when the application starts
- Simple command-line interface (CLI)

## 🧰 Tools & Concepts

- Python 3
- vscode
- File Handling (`open()`)
- Lists
- Loops and Conditional Statements
- Functions
- Exception Handling
- User Input

## 📂 Project Structure

```
todo-list-app/
│
├── todo.py
├── tasks.txt
```

## ▶️ How to Run

1. Clone the repository:

```bash
git clone https://github.com/your-username/todo-list-app.git
```

2. Navigate to the project directory:

```bash
cd todo-list-app
```

3. Run the application:

```bash
python3 todo.py
```
